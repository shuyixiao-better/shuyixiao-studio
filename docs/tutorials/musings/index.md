# 漫思录

> *思绪如水，漫溯而上，记录生活与技术的点滴思考*

## 专栏简介

**漫思录**收录的是不适合放进教程类专栏、但值得认真写下来的思考：对行业事件的观察、对技术趋势的判断，以及工作中沉淀出的方法论。

和教程专栏不同，这里的文章更关注"为什么"和"意味着什么"，而不只是"怎么做"。每篇文章都会给出事实依据、自己的分析框架和结论，方便你核对、反驳或者引用。

## 写作原则

- **先有事实，再有观点**：引用的数据和事件都注明来源
- **观点可以被验证**：给出判断时说明依据和前提，方便日后回看
- **持续修订**：当事实发生变化时，会在原文中补充更新说明
